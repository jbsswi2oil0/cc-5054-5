# IVC1 documented examples

Generated by `node tools/doc/docs.mjs --write` from `examples/*.json`.

Every stream here was written by `tools/doc/miniwriter.mjs` from a plain
coefficient table; the main encoder (`src/encode.js`) is not called.

## Smallest example

Smallest documented example: one 8x8 block, one non-zero level (DC=16).

| field | bits | value |
|---|---|---|
| header | 0..79 | magic, version, size, qbase, flags |
| qsel | 79..81 | 0 |
| mode | 81..84 | 0 (RAW) |
| numAC | 84..85 | 1 |
| DC | 85..96 | 16 |

Total 96 bits, 12 bytes.  Block bits:

```
00000100 00011111 1
```

Hex:

```
000000  49 56 43 31 10 07 00 70 f0 00 08 3f
```

## Two blocks sharing a prediction edge

Two horizontally adjacent 8x8 blocks. Block 0 ends on a byte boundary with a negative AC level; block 1 predicts from block 0's right column.

Coefficient tables (zig-zag levels, DC first):

```
block 0: qsel=0 mode=0 dc=-3 ac=[-4, -3]
block 1: qsel=0 mode=2 dc=2 ac=[]
```

Block 0 occupies bits [79, 112) and ends on a byte boundary.  Its last AC level is -3 at zig-zag position 2, carried by bits [105, 112).
Block 1 uses mode 2 (H) and predicts from block 0's right column.

Published block directory (only verified entries):

| block | bits | published |
|---|---|---|
| 0 | 79..112 | true |
| 1 | 112..123 | true |

### Damaged tails

| damage | bytes | reported at bit | block | note |
|---|---|---|---|---|
| missing last byte | 15 | 120 | 1 | true last byte lost |
| misplaced end marker | 16 | 128 | 1 | byte count correct |

The two report at different bit positions: the real byte loss fails inside
block 1 at bit 120, while the byte-complete but
mis-aligned stream fails at the stored end, bit 128.

### A bit flip that only the neighbour reveals

Bit 109 (inside block 0's last AC codeword) is inverted.  Block 1's own codewords and bit range are unchanged: true.
The decode still reports success: true.
Pixel (8, 0) in block 1 is 132 in the intact
stream and 160 in the damaged one, although block 1's payload is identical.

## Checking and reverse lookup

```
node tools/doc/check.mjs check   examples/shared-edge/stream.ivc
node tools/doc/check.mjs check   examples/shared-edge/unknown-version.ivc
node tools/doc/check.mjs check   examples/shared-edge/missing-last-byte.ivc
node tools/doc/check.mjs lookup  examples/shared-edge/stream.ivc 8 0
node tools/doc/check.mjs explain examples/shared-edge/shared-edge-flip.ivc examples/shared-edge/stream.ivc 8 0
node tools/doc/check.mjs directory examples/shared-edge/missing-last-byte.ivc
node tools/doc/check.mjs seek    examples/shared-edge/stream.ivc 1
```

The unknown-version stream is rejected at bits [32, 36) = "0010", with no block-level failure reported.

## Published legacy example

`examples/legacy/blocks-v1.ivc` is frozen at 26 bytes / 202 bits.
`node tools/doc/side-by-side.mjs` prints its raw bits next to a freshly parsed
stream, so the parser and the miniature writer are checked against the published
example rather than against each other.

## Rebuilding after a quantiser change

```
node tools/doc/quantiser.mjs --table new-qm.json --diff old-qm.json
```

Reports, per documented sample, whether the rebuilt stream changes length and
whether the OLD decoder still returns the original pixels from it.
